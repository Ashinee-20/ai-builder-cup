# Design reference

Inspected `https://www.firecrawl.dev/` on 17 October 2026. Its live HTML exposed a Suisse-first stack, near-white `#f9f9f9` canvas, charcoal text, orange heat tokens, hairline boundaries, container rails, grid details, white controls, and compact labels.

ChalkEvo uses those broad principles, not Firecrawl assets or layouts. System/Inter fallback is used because no licensed Suisse files were supplied. `--canvas: #f8f8f6`, `--ink: #262626`, and `--heat: #fa5d19` are close sRGB approximations. Landing/onboarding use a pale grid; lesson reading is quieter. The mark, copy, workflow preview, concept map, and layouts are original.

Browser-computed inspection was unavailable during the initial reference pass; values beyond HTML-exposed tokens and supplied observations remain approximations.
