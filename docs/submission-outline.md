# Submission outline

- **Problem:** turn what was taught into approved resources and use students’ explanations in the next lesson.
- **Theme fit:** Media, Content & Digital Experiences—multimodal lesson capture becomes reviewable educational content and interactive learning.
- **Implementation:** Next.js/TypeScript, Firebase, Cloud Run/Tasks, and Gemini; deterministic checks surround bounded AI tasks.
- **Differentiation:** one teacher-controlled daily loop; explanation evidence remains separate from input quality; revisions preserve originals and link to evidence.
- **Business hypotheses:** teachers/schools may value preparation support and auditable formative evidence. These are unvalidated hypotheses.
- **Limitations:** local persistence; incomplete production services; synthetic curriculum, roster, recap and responses; no classroom pilot or organizer clearance.
- **Provenance:** fresh repository code. Firecrawl informed broad visual principles; assets, layouts, copy and demo curriculum are original.
